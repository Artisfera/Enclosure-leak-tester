# AI experiment

Out of curiosity, I decided to see how GPT-6 Astra and GPT-5.6 Terra would handle this task. They actually managed to do it, and the PID parameters they calculated look promising, so the experiment itself turned out to be pretty interesting.

I do not plan to use the AI-generated code in the final version of the project though. Even with fairly detailed prompts, the resulting code is, in my opinion, much more complicated than it needs to be. It is hard to read, has a lot of unnecessary layers, and it is difficult to learn anything from it. You could say it turned into a half-readable black box, at least from my perspective as a beginner.

At first I wanted to simply delete this version, but I decided to keep it.

If, like me, you are still learning embedded systems, C or control systems, this can actually be a pretty good lesson. AI can quickly make something that works, but it can just as quickly do things for you that you could understand and write yourself after a bit of learning, and you would probably get a lot more out of that than spending time fighting with AI-generated code. :)
